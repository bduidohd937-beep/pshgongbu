# PSH 공부

생활과 윤리·사회문화 모바일 학습 MVP.

## 콘텐츠 검증 규칙

공개 카드에는 사용자가 제공한 2027 수능특강 또는 2027학년도 평가원 6월·9월 모의평가의 출처와 페이지·문항 번호, 원문 대조 기록이 모두 있어야 합니다. 검증 전 콘텐츠는 공개 앱 데이터에서 차단하며, 카드별 감사 결과는 `content-audit.json`에 기록합니다.

개념 카드는 참고 자료를 바탕으로 독자적으로 재서술한 시연 콘텐츠입니다. 업로드된 평가원 문제지·해설지와 EBS PDF 원문은 공개 저장소에 포함하지 않았습니다. 현재 문제 탭은 권리 확인 전 시연용 재구성 문항만 제공합니다.

## 2027 6·9월 모의평가 학습 카드 (V0.3.2)

기출 해설을 독립 문장으로 재구성한 44장 중 28장(생윤 13장, 사문 15장)을 검증해 공개했습니다. 나머지 16장과 이전 샘플 24장은 공개되지 않습니다. 정확한 문제/해설 출처와 승인 상태는 `content-audit.json`에서 확인하세요. 원본 PDF, 강의 대본 및 정답 해설 전문은 저장소에 저장하지 않습니다. 문제 탭은 아직 검증된 문항이 없어 검증 대기 안내가 표시됩니다.

## V0.3.3 — 주제별 통합 개념 카드
- 개념 탭은 주제별 비교 노트로 변경했습니다: 생윤 9개, 사문 12개. 한 카드에 관련 사상가·이론의 주장, 비교 포인트, 시험 함정을 모읍니다.
- 문제 탭은 기존에 검증된 **기출 문항별 복습 카드 28장**을 보여 줍니다. 실제 기출 문제 원문/선택지는 제공하지 않으며 5지선다 문제 제작과 구분합니다.
- EBS 직접 재구성 주제는 2027 수능특강 교재의 쪽수를 근거로 기록합니다. 나머지 주제는 V0.3.2의 검증된 문장만 재배치했습니다.
- 미검증 기존 24장과 검증 보류 16장은 공개하지 않습니다.
- 긴 개념 노트는 카드 내부에서 스크롤하며, 다음/이전 버튼 또는 카드 끝 스와이프로 이동합니다.
- 기존 과목 선택, 다크 모드, 진도 저장을 유지합니다.

- 본문 카드는 단원 선택 후 읽습니다. 기존 하단 '이전/다음/진도 초기화' 3버튼을 삭제해 학습 영역을 확대했고, 짧은 카드는 세로 스와이프, 긴 카드는 본문 스크롤 끝에서 한 번 더 스와이프하여 이동합니다. PC는 좌·우 화살표로 이동합니다.
- `topic-audit.json`에는 카드별 교재 근거·검증 상태·단원별 공개 카드 수를 기록합니다. **31강 전부 완성 또는 126개 주제 전부 검증된 상태가 아니며**, 각 단원의 기본·실전 문제 전체를 대조했다는 뜻도 아닙니다.
- 기존 미검증 샘플 **24장(blocked)**, 검증 보류 기출 초안 **16장(pending)**은 여전히 비공개입니다. 공개 저장소에 원본 교재·기출·해설 PDF 전문을 포함하지 않습니다.

## V0.3.5 — 31강 학습 카드 확대
- 생활과 윤리 15강·사회·문화 16강 모든 단원에 최소 1개 이상의 학습 노트를 배치. 신규 92장(생윤51·사문41)으로 **총 120장(생윤63·사문57)** 제공. 단원별로 사상가 비교·핵심 개념·수능 함정을 정리한다.
- 교재의 126개 주제 후보는 **학습 범위 색인**이며, **모든 기본·실전 문항과 예외 조건까지 전수 검증됐다는 뜻은 아니다.** 단원 전체를 완료로 표시하지 않는다.
- 신규 학습 노트는 제공된 2027 수능특강 본문 설명을 재서술하고 근거 인쇄 페이지를 각 카드에 표기한다. 검증 이력은 `topic-audit.json`에 기록한다. 교재·해설 원문은 공개 저장소에 업로드하지 않는다.
- 문제 탭의 기출별 복습 카드 28장과 미검증 카드 24장 차단·16장 보류 상태는 그대로 유지한다.
- 모바일 카드 하단 버튼 삭제·내부 스크롤·스와이프는 V0.3.4를 유지한다.

## V0.3.6 — 모바일 PWA

- 카드 내부는 세로로 스크롤하고 다음·이전 카드는 좌우 스와이프 또는 상단 작은 화살표로 이동합니다.
- Android Chrome에서 홈 화면의 '휴대폰에 앱 설치' 버튼이나 브라우저 메뉴의 '앱 설치/홈 화면에 추가'로 설치할 수 있습니다. 이 방식은 별도 APK가 아닌 PWA입니다.
- 첫 온라인 방문 시 서비스 워커가 학습 카드·화면 파일을 캐시합니다. 이후 인터넷 없이 저장된 개념·기출 복습 자료를 읽을 수 있습니다.
- 진도와 다크 모드는 기기의 로컬 저장소를 사용합니다. 별도의 기기 간 동기화는 없습니다.
- 설치 동작 및 오프라인 기능의 최종 휴대폰 실기기 확인은 필요합니다.

## V0.3.7 — 개념 카드 고정 및 설치 앱 캐시 갱신
- 긴 카드에서 카드 테두리와 제목을 고정하고 사상가별 본문만 독립적으로 세로 스크롤하도록 분리했습니다. 개념/기출 복습 탭 모두 적용합니다.
- 카드 이동은 좌우 스와이프·상단 이전/다음 화살표로 유지하며, 카드 전환 시 슬라이드업/다운 애니메이션을 제거해 화면이 함께 밀리지 않도록 수정했습니다.
- 앱에 설치된 이전 캐시가 수정 이전의 CSS와 JS를 계속 제공하는 것을 방지하려고 파일 주소에 V0.3.7 버전을 지정했습니다. 서비스 워커 캐시 버전을 변경하고 새 앱 버전의 파일을 다시 저장합니다.
- 설치형 앱은 서비스 워커 업데이트 후 한 번 갱신되도록 연결했습니다. 설치 삭제나 학습 진도 초기화는 필요하지 않습니다.
- 기존 120장 개념 카드, 28장 기출 복습, 다크 모드, 진도 저장, 미검증 카드 차단은 그대로 유지됩니다.
- 테스트: 코드 실행 모의(본문 분리·세로 유지·가로 카드 이동·뒤로 이동), 오프라인 캐시 파일 18개 확인. 모바일 실기기 확인은 사용자 테스트 필요.


## V0.4.0 패치 1 — 쇼츠형 조작 안정화 (실기기 검증 대기)

- **메인 개념 피드**: 카드당 기존 검증 콘텐츠 중 첫 3개 항목을 미리보기로 표시. 긴 본문은 이 피드에서 스크롤하지 않음.
- **카드 이동**: 한 손가락의 의도적인 위/아래 스와이프로 각각 다음/이전 카드 1장만 이동. 최소 판정 거리는 화면 높이의 약 18%이며 100~160px 사이로 제한, 대각선 이동·탭·버튼 시작 제스처는 제외. 제스처 사이 400ms 중복 방지.
- **상세 학습**: '전체 개념 자세히 보기'를 누르면 스와이프 피드와 분리된 스크롤 화면에 검증된 전체 사상가 주장·수능 함정·출처 표시. 닫으면 원래 카드로 복귀하며 Android 뒤로 가기로도 닫을 수 있게 설계.
- **기출 탭**: 기존 28장 문항별 복습도 동일한 피드/상세 구성을 사용. 실제 문제지 원문이 아님.
- 콘텐츠 자체를 변경하지 않음: 생윤 개념 63장, 사문 57장, 기출 복습 28장, 기존 콘텐츠 검증 게이트·학습 진도·다크 모드 유지.
- 설치 앱 갱신: `psh-v040-p1` 새 캐시, 버전별 CSS/JS 주소 사용. 홈에 `V0.4.0 P1` 버전 표시로 갱신 확인 가능.
- 코드 단위 제스처·상세 화면·캐시 회귀 테스트는 진행하지만, **Android 설치형 PWA의 실제 제스처 테스트가 끝나기 전에는 완료로 판정하지 않는다.**
- **후속 패치**: 쇼츠형 상세 UI 디자인(패치 2), 좋아요·개인 메모·즐겨찾기(패치 3). 본 패치에서는 추가하지 않음.


## V0.4.1 — 빠른 복습 · 정독 모드 · 취약 카드 필터

- **빠른 복습**: V0.4.0 P1 쇼츠형 화면 유지. 세로 스와이프로 카드 1장씩 이동. 요약만 보여주고 필요할 때 `전체 개념 자세히 보기`도 사용 가능.
- **정독 모드**: 같은 개념 카드의 **전체 사상가별 주장·수능 함정·교재 출처**를 곧바로 볼 수 있음. 세로 스크롤은 본문 읽기에만 사용하고, 카드 이동은 좌우 스와이프 또는 상단 ‹ › 화살표로만 가능. 뒤로 돌아가서 상세 보기 버튼을 반복해서 누를 필요 없음.
- **이해도 기록**: 각 개념에 `✓ 알겠음`, `? 모르겠음` 표시. 다시 누르면 해제 가능. 과목+카드 ID로 구분해 `localStorage:psh-ratings-v041`에 로컬 저장.
- **모르는 카드만**: 현재 과목/단원에서 미이해 표시한 카드만 보여줌. 정독으로 전환해도 동일한 카드 ID와 기록을 사용. `알겠음`으로 바꾸면 취약 카드 모음에서 제외됨. 0장이면 안내 메시지와 필터 해제 버튼이 보이므로 막힌 상태로 남지 않음.
- 모드/필터 설정은 `localStorage:psh-view-v041`에 독립 저장. 기존 `psh-progress`/다크 모드 저장은 변경하지 않음. 과목 변경 시 빈 취약 목록에 갇히지 않도록 필터를 전체로 돌림. 랜덤 목록과 필터 전환 시 기존 임시 정렬을 초기화함.
- **문제 탭**: 기존 기출 문항별 개념 복습 28장 그대로 사용(실제 5지선다 원문 아님). 이해도 기록과 취약 필터는 개념 탭 전용.
- **콘텐츠/감사 보존**: 2027 수능특강 학습 개념 120장(생윤 63·사문57), 기존 차단 24장·보류 16장 그대로. 새로운 철학자 주장·검증되지 않은 설명을 추가하지 않음.
- PWA 캐시 버전을 `psh-v041`, 앱 CSS/JS 리소스 버전을 `?v=041`로 갱신해 설치형 앱 자동 업데이트 지원.
- 코드 모의 검증: 미세 터치 30회 이동 0건, 빠른 복습 스와이프 1장 이동, 정독 세로 스크롤 불간섭·가로 이동, 정독 상태에서 기록 시 스크롤 유지, 취약 목록 1→0 및 다시 추가, 기록 재실행 후 유지, 문제 탭, 검증 게이트, 캐시 스크립트 목록 통과. **실제 휴대폰 PWA 실기기 확인 전에는 최종 검증 완료로 표시하지 않음.**
- 좋아요/개인 메모/즐겨찾기는 이후 독립 패치에서 검토하며 이번 릴리스에 포함하지 않음.


## V0.4.2 — 좋아요·개인 메모·즐겨찾기·복습 목록

- **좋아요**: 유용한 개념에 표시하거나 해제. **즐겨찾기**: 다시 보고 싶은 개념을 별도로 표시하거나 해제.
- **개인 메모**: 카드마다 기기 내부에 나만의 한글 메모를 작성·수정·명시적으로 저장하거나 삭제한다. 2,000자 제한, 미저장 변경 상태에서 닫으려면 확인. 다른 사용자와 메모를 공유하거나 서버로 보내지 않는다.
- **복습 목록**: 상단 메뉴에서 `전체 카드 / 모르는 카드 / 즐겨찾기 / 좋아요`를 한 번에 하나만 선택. 단원 선택과 연계하고, 빠른 복습·정독 모드 간 동일한 카드 ID에 연결된 정보를 사용한다. 선택한 목록에 카드가 없으면 안내를 보여준다.
- **저장**: 좋아요·즐겨찾기·개인 메모는 `psh-personal-v042` 아래 카드 고유 키 `과목:카드ID`에 저장. 기존 `psh-ratings-v041`, `psh-progress`, `psh-theme`은 유지하며, `psh-view-v041`에서 모드와 '모르는 카드만' 기존 설정을 새 `psh-view-v042` 필터로 마이그레이션한다.
- **터치 보호**: 개인화 버튼에서 터치를 시작하면 쇼츠 피드 제스처를 처리하지 않는다. 메모 편집 중 또는 긴 개념 상세 보기 중에는 카드가 넘어가지 않는다. 정독 모드에서 좋아요·메모·즐겨찾기를 수정해도 위아래 본문 스크롤은 유지한다.

## V0.5.0 — 실제 5지선다 문제 풀이 MVP

- 새 **실전 문제** 탭을 `개념 / 실전 문제 / 기출 복습` 사이에 추가했다. 실전 문제는 `practice-v050.js`의 **새로 작성한 5지선다 총 20문항(생윤 10·사문 10)**이며, 평가원/EBS 기존 문제 원문을 복사한 것이 아니다. 출제 범위는 13개 강으로 한정하며 31강 전체를 완성했다고 주장하지 않는다.
- 수험생은 한 문제에서 ①~⑤ 중 하나를 선택하고 `정답 확인`을 눌러야 채점된다. 채점 후 정답 번호, 전체 5개 선택지의 정오 이유, 핵심 함정 요약, EBS PDF 근거 페이지가 표시된다. 정답을 보기 전에는 해설과 정답을 노출하지 않는다.
- 모든 문제에는 별도 ID, 과목·단원, 5개 선택지, 0~4 인덱스 정답, 선택지별 해설 5개, 핵심 개념과 PDF 페이지 근거를 보유하며 `status=source-checked`·`kind=original-five-choice`·정답/해설 개수 검증을 통과한 문제만 공개된다. 출처/범위 기록은 `practice-audit-v050.json`을 참조한다.
- 오답 기록은 `localStorage:psh-practice-v050`에 과목+문제 ID로 저장. 최근 풀이 기준 정답/오답, 시도 횟수, 선택 번호, 채점 여부를 유지한다. `오답만 다시 풀기`는 **마지막 채점이 오답인 문제만** 표시하며, 다시 맞힌 후 해설을 읽을 때까지 문제를 유지하고 다음 문제로 넘어가면 필터에서 제외한다. 전부 맞혔다면 0장 안내를 제공한다.
- 문제 탭에서는 선지 본문을 세로로 읽을 수 있도록 독립적인 스크롤을 적용하고, 세로 스와이프로 문제가 넘어가지는 않는다. 상단 ◀▶ 또는 채점 후 `다음 문제`로 이동. 기존 개념 Shorts 세로 전환과 정독 좌우 전환은 보존한다.
- 이전 **기출 복습** 탭은 **28장 기출 문항별 개념 복습 노트**로 따로 유지한다. 이는 새로운 정답 선택·채점 기능의 문항과 구별된다.
- 첫 EBS 기반 20문항은 실전 풀이 MVP이며, 출제 난도·함정·31강 범위는 수능 대비 후속 패치에서 확장해야 한다.
- 기존 원본 카드 120장, 차단 24장·보류 16장, 좋아요·메모·즐겨찾기, 취약 개념 기록, 로컬 진도는 변경하지 않는다. 설치형 앱 캐시 `psh-v050`, CSS/JS `?v=050` 및 문제 데이터 `practice-v050.js` 선캐시로 오프라인 이용 지원.
- 코드 모의 테스트와 문항 데이터 검사 통과 여부는 PR에 기록한다. 실제 갤럭시 설치 앱 조작·오프라인 재실행은 사용자 실기기 확인 필요. 학습 기록은 서버 동기화·자동 백업을 제공하지 않는다.
