# PSH 공부

생활과 윤리·사회문화 모바일 학습 MVP.

## 콘텐츠 검증 규칙

공개 카드에는 사용자가 제공한 2027 수능특강 또는 2027학년도 평가원 6월·9월 모의평가의 출처와 페이지·문항 번호, 원문 대조 기록이 모두 있어야 합니다. 검증 전 콘텐츠는 공개 앱 데이터에서 차단하며, 카드별 감사 결과는 `content-audit.json`에 기록합니다.

개념 카드는 참고 자료를 바탕으로 독자적으로 재서술한 시연 콘텐츠입니다. 업로드된 평가원 문제지·해설지와 EBS PDF 원문은 공개 저장소에 포함하지 않았습니다. 현재 문제 탭은 권리 확인 전 시연용 재구성 문항만 제공합니다.

## 2027 6·9월 모의평가 학습 카드 (V0.3.2)

기출 해설을 독립 문장으로 재구성한 44장 중 28장(생윤 13장, 사문 15장)을 검증해 공개했습니다. 나머지 16장과 이전 샘플 24장은 공개되지 않습니다. 정확한 문제/해설 출처와 승인 상태는 `content-audit.json`에서 확인하세요. 원본 PDF, 강의 대본 및 정답 해설 전문은 저장소에 저장하지 않습니다. 문제 탭은 아직 검증된 문항이 없어 검증 대기 안내가 표시됩니다.
